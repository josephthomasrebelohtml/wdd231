Site Plan - ViajaWeb

Site Name

ViajaWeb

This site name is for a travel agency called ViajaWeb, Viaja is a word in Portuguese for "travel", while mixing Portuguese and English together to show that it's main target is foreigners wanting to visit Brazil.

Optional Domain Name: viaja-web.org

Site Purpose

to facilitate customers travel plans.

to facilitate customers wanting to learn more about the travel packages, their benefits and the various interesting facts, places and foods located in the large country that is Brazil.

Scenarios

to facilitate customers travel plans.

  • What benefits can I expect from the travel packages offered by this company?
  • What interesting information about this country can I expect to use if I go there?
  • How will this company facilitate my travel plans?

Color Scheme

Green = #186636

This color will be used in the header, footer and buttons

White = #FFFFFF

This color is great for the text that will be included when the background color uses a variant of Green or Blue. So, this will be for the text whenever either of these colors are used.

Blue = #002776

This color will be for hover animations for buttons and other places to add more variety to the website.

Black = #000000

This color will be for the text that is inside white or other light colored backgrounds.

Typography

Merriweather Sans

This font will be used for most of the text in the websites; header, footers, body texts, etc.

Roboto Slab

This font will be used for special items inside the website, like buttons, pricing, travel package details, etc.
